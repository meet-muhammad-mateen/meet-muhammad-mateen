### 🏛️ Engineering Philosophy & Core Focus

I architect software with a strict focus on **clean separation of concerns, end-to-end type safety, and real-world performance**. I do not build with fragile templates or short-lived shortcuts. Every product is engineered to be modular, scalable, and easy to maintain from initial prototype to production deployment.

#### Where I Deliver Maximum Value:
- **Production Full-Stack Systems:** Building end-to-end web applications with Next.js App Router, React 18, TypeScript, and modern styling architectures that achieve sub-second TTFB and zero layout shift.
- **Robust Backend & API Infrastructure:** Designing secure, asynchronous REST microservices in FastAPI and Django, coupled with PostgreSQL and Supabase for relational data integrity and real-time synchronization.
- **Autonomous AI & Scraping Pipelines:** Orchestrating complex automation graphs in **n8n**, integrating LLM reasoning (OpenAI GPT-4o, Google Gemini), and writing headless **Playwright** bots that reliably extract structured datasets from dynamic JavaScript applications.

### 🚀 Production Engineering Case Studies

#### 1. 🎓 [College Digital Hub](https://apsac-nmc-bwp.vercel.app/) — Academic Portal & Management System
> **Architecture:** Decoupled Next.js App Router (Vercel Edge) + Asynchronous FastAPI Microservice Backend + Supabase PostgreSQL  
> **Live Portal:** **[https://apsac-nmc-bwp.vercel.app/](https://apsac-nmc-bwp.vercel.app/)**

- **The Problem:** Fragmented student communication, high latency on administrative circulars, and unsecured public departmental files.
- **Engineering Solution:** Architected a decoupled edge-rendered Next.js frontend with sub-second page loads. Backed by FastAPI asynchronous endpoints for administrative tasks, secured with Supabase Row-Level Security (RLS) policies to isolate sensitive administrative records from public student notices.

---

#### 2. 🏢 [LandDesign Analytics](http://54.162.190.58/) — Commercial Real Estate Zoning Intelligence
> **Architecture:** Django MVC + PostgreSQL + Headless Playwright Ingestion + AWS EC2 Linux  
> **Live Platform:** **[http://54.162.190.58/](http://54.162.190.58/)**

- **The Problem:** Commercial real estate developers spend countless hours manually searching municipal county GIS portals for parcel zoning classifications and permit revisions.
- **Engineering Solution:** Built automated headless Playwright scrapers that traverse dynamic JavaScript portals, extract municipal parcel data, and normalize it into a PostgreSQL schema through Django ORM. Deployed on an AWS EC2 Ubuntu instance with Gunicorn and Nginx reverse proxying.

---

#### 3. 🎨 [After Concept Platform](https://www.afterconcept.io) — Digital Agency Architectural Redesign
> **Architecture:** Modular Tailwind CSS Component Hierarchy + Semantic HTML5 + Netlify Edge  
> **Live Site:** **[https://www.afterconcept.io](https://www.afterconcept.io)**

- **The Problem:** The corporate agency platform suffered from monolithic legacy stylesheets, high layout debt, and inconsistent responsive rendering on mobile devices.
- **Engineering Solution:** Led the complete frontend overhaul. Refactored the entire presentation tier into modular, reusable Tailwind CSS components, eliminated layout shift, and achieved 100% WCAG 2.1 accessibility compliance. Formally certified and commended by CEO Uzair Rasheed.

---

#### 4. 📚 [BookShelf.pk](https://bookshelfonline.netlify.app/) — Client-Side E-Commerce Bookstore
> **Architecture:** React 18 + TypeScript + Vite + TanStack Query v5 + Tailwind CSS v4  
> **Live App:** **[https://bookshelfonline.netlify.app/](https://bookshelfonline.netlify.app/)**

- **The Problem:** Traditional e-commerce catalog browsing is often sluggish and blocked by repeated roundtrip network requests.
- **Engineering Solution:** Engineered declarative server-state management using TanStack Query v5, implementing in-memory caching and stale-while-revalidate fetching so catalog transitions are instantaneous. Paired with lightweight wouter routing and fluid Framer Motion animations.
